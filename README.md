# ⚡ Painel de Carregamento

## 🤝 Projeto em parceria com a GoodWe

Este projeto foi desenvolvido em parceria com a **GoodWe**, como uma experiência prática de desenvolvimento de uma interface para gerenciamento e acompanhamento de carregamento de veículos elétricos.

Durante o desenvolvimento, trabalhei na construção da aplicação utilizando **React, TypeScript e Vite**, explorando também ferramentas de **Inteligência Artificial para auxiliar no processo de desenvolvimento**, incluindo **Claude e Antigravity**.

A utilização dessas ferramentas fez parte do processo de desenvolvimento, desde a exploração de ideias e estruturação da aplicação até auxílio na implementação e revisão de componentes, permitindo experimentar novas formas de trabalhar com IA integrada ao desenvolvimento de software.

## 📌 Sobre o projeto

O projeto consiste em um painel de carregamento para veículos elétricos, desenvolvido para permitir o acompanhamento e gerenciamento de sessões de carregamento através de uma interface web.

### ✨ Principais funcionalidades

* ⚡ Seleção de sessão de carregamento
* 🔋 Acompanhamento do progresso da carga
* 📊 Dashboard com informações da sessão
* 🕒 Histórico de carregamentos
* 💾 Persistência de dados utilizando LocalStorage
* 🔔 Sistema de notificações
* 📱 Interface responsiva

## 🛠️ Tecnologias

* **React**
* **TypeScript**
* **Vite**
* **CSS**
* **LocalStorage**
* **Git & GitHub**

### 🤖 Ferramentas de IA utilizadas

* **Claude**
* **Antigravity**

## 🎯 Experiência

Este projeto foi uma oportunidade de aplicar conhecimentos de desenvolvimento frontend em um contexto próximo ao mercado, trabalhando a partir de uma demanda real e explorando o uso de ferramentas de Inteligência Artificial como parte do processo de desenvolvimento.

Além da implementação técnica, o projeto proporcionou experiência com organização de código, componentização, gerenciamento de dados no navegador e desenvolvimento de uma aplicação pensando na experiência do usuário.
